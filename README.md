# Contaminant Jelly

A jellyfish that gathers a counter-archive of film, after McLuhan's hot and cool media and the projectionist's reel in *Cinema Paradiso*.

This repository was split out of [hartswf0/bolas](https://github.com/hartswf0/bolas) (PAELEO / SCION) because that site had grown past GitHub Pages' 1 GB limit. Paths keep the same layout as in `bolas`, so the pages work unchanged.

- `paeleo/scion/videotext/maker.html`: **Memory Maker.** Swim the films, shape a memory, dream it, share it. See `MEMORY_MAKER.md`.
- `paeleo/scion/contaminant.html?play=1`: **the swim game.** See `videotext/THEORY_OF_PLAY.md`.
- `paeleo/scion/videotext/editor.html`: **the editor.**
- `paeleo/scion/contaminant.html`: **the films and their records.**
- `paeleo/handmade/`: the fourteen public-domain archive frames and their rights manifests.
- Other films used by the Memory Maker: `paeleo/media`, `flour-tower`, `its-all-right`, `abominable-house`.
