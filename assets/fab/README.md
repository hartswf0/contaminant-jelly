# Real Jelly environment assets

These redistributable Poly Haven assets are [CC0](https://polyhaven.com/license). They are public-build substitutes for the Quixel Fab scans.

| File | Source | Preparation |
| --- | --- | --- |
| `seabed/basecolor.jpg`, `seabed/normal.jpg`, `seabed/roughness.jpg` | [Sand 01](https://polyhaven.com/a/sand_01) | 1K JPEGs. The normal map is OpenGL (+Y). |
| `reef-rock-01.glb` | [Coast Rocks 01](https://polyhaven.com/a/coast_rocks_01) | 5,437 triangles, with embedded 1K base color, normal, and packed occlusion/roughness/metallic textures. |
| `reef-rock-03.glb` | [Coast Rocks 03](https://polyhaven.com/a/coast_rocks_03) | 6,504 triangles, with the same texture layout. |

The rock scans retain their source scale. Adjust scale and placement in the scene for the tank and the reef crossings.
